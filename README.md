# CDC Mobile Mechanic — painel de leads

Relatório de publicidade paga (Meta Ads e Google Ads) da CDC Mobile Mechanic,
mecânica móvel na Gold Coast, Austrália.

O painel está em `index.html` — página única, sem dependências externas
além das fontes do Google Fonts.

**Lead** = quem preencheu e enviou o formulário do site, ou fez a marcação
no book.servicem8.

Gerado a partir de `gerar.py` (fora deste repositório) com dados das APIs
do Meta Ads e do Google Ads.
